# Photo credits

All photos are from [Pexels](https://www.pexels.com) and used under the
[Pexels License](https://www.pexels.com/license/): free for personal and commercial use,
no attribution required. They are credited here anyway, as thanks.
They are demo photos, so replace them with your own dishes before launch.

Each file was downloaded from the Pexels image server, then cropped to 4:3 and resized to
1200 × 900 (the hero to 2000 px wide) and saved as an optimised JPEG.
Every photo was checked by eye against its dish.

To replace one, overwrite the file with the same name (any aspect ratio works;
4:3, about 1200 px wide, is ideal). To rename, update `image` in
`packages/shared/src/seed/menu.ts`. The hero image path is in `config/brand.ts`.

The photographer is listed where the Pexels search listing named them; for the others,
see the photo page.
